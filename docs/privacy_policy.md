# プライバシーポリシー

最終更新日: 2026年6月8日

本プライバシーポリシーは、Android アプリ「となり」（以下「本アプリ」）におけるデータの取り扱いについて説明します。

## 本アプリの概要

本アプリは、ユーザーが自身で用意した AI サービスの API キーを使用して、AI との対話を行うコンパニオンアプリです。対応する AI サービスは Anthropic Claude API および OpenAI 互換 API（OpenAI、Groq 等）です。

## 収集・使用するデータ

本アプリは以下のデータを端末上で取得し、ユーザーが設定した AI サービスへの送信に使用します。いずれもユーザーが明示的に機能を有効にした場合にのみ取得されます。

| データの種類 | 用途 | 送信先 |
|---|---|---|
| カメラ画像（前面・背面） | HeartBeat 機能で AI に周囲の状況を伝える | ユーザーが設定した API サービス |
| マイク音声 | HeartBeat 機能で AI に周囲の音を伝える | ユーザーが設定した API サービス |
| 位置情報 | AI に現在地の情報を伝える | ユーザーが設定した API サービス |
| 加速度センサー | 動き・姿勢の検知、睡眠判定 | ユーザーが設定した API サービス |
| スクリーンショット | AI に画面の内容を伝える | ユーザーが設定した API サービス |
| 睡眠データ（Health Connect） | 睡眠の記録・AI への共有 | ユーザーが設定した API サービス |

## データの保存

- **会話履歴・睡眠ログ・設定**: 端末内のローカルデータベースに保存されます。開発者のサーバーには送信されません。
- **API キー**: Android Keystore を使用して端末内に暗号化保存されます。外部には送信されません。
- **カメラ画像・音声**: AI への送信時に一時的に処理され、端末内に永続保存されません（チャット内のサムネイルを除く）。

## データの共有

本アプリは、ユーザーが設定した AI サービス以外の第三者にデータを送信しません。

データの送信先は、ユーザーが接続設定で選択した API プロバイダーおよび Base URL によって決まります。各サービスのデータ取り扱いについては、それぞれのプライバシーポリシーをご確認ください。

- [Anthropic のプライバシーポリシー](https://www.anthropic.com/privacy)
- [OpenAI のプライバシーポリシー](https://openai.com/policies/privacy-policy)

## 第三者サービス

本アプリは以下の第三者サービスを利用する場合があります。

- **Anthropic Claude API / OpenAI API / その他 OpenAI 互換 API**: ユーザーが入力した API キーを使って、ユーザー自身のアカウントで利用されます。送信先はユーザーの設定により決まります
- **Google Health Connect**: ユーザーが許可した場合のみ、睡眠データの読み取りに使用されます

## データの削除

アプリをアンインストールすることで、端末内の全データ（会話履歴、設定、暗号化された API キー）が削除されます。アプリ内からも個別の会話履歴を削除できます。

各 AI サービスに送信されたデータの削除については、それぞれのサービスのポリシーに従います。

## 子どものプライバシー

本アプリは 13 歳未満の子どもを対象としていません。

## 変更について

本ポリシーは予告なく変更されることがあります。重要な変更がある場合はアプリ内で通知します。
