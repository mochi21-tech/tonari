# プライバシーポリシー

最終更新日: 2026年6月8日

本プライバシーポリシーは、Android アプリ「となり」（以下「本アプリ」）におけるデータの取り扱いについて説明します。

## 本アプリの概要

本アプリは、ユーザーが自身で用意した AI サービス（Anthropic Claude API）の API キーを使用して、AI との対話を行うコンパニオンアプリです。AI サービスの提供元は Anthropic, PBC です。

## 収集・使用するデータ

本アプリは以下のデータを端末上で取得し、ユーザーが設定した AI サービスへの送信に使用します。いずれもユーザーが明示的に機能を有効にした場合にのみ取得されます。

| データの種類 | 用途 | 送信先 |
|---|---|---|
| カメラ画像（前面・背面） | HeartBeat 機能で AI に周囲の状況を伝える | Anthropic API |
| マイク音声 | HeartBeat 機能で AI に周囲の音を伝える | Anthropic API非対応 |
| 位置情報 | AI に現在地の情報を伝える | Anthropic API |
| 加速度センサー | 動き・姿勢の検知、睡眠判定 | Anthropic API |
| スクリーンショット | AI に画面の内容を伝える | Anthropic API |
| 睡眠データ（Health Connect） | 睡眠の記録・AI への共有 | Anthropic API |

## データの保存

- **会話履歴・睡眠ログ・設定**: 端末内のローカルデータベースに保存されます。開発者のサーバーには送信されません。
- **API キー**: Android Keystore を使用して端末内に暗号化保存されます。外部には送信されません。
- **カメラ画像・音声**: AI への送信時に一時的に処理され、端末内に永続保存されません（チャット内のサムネイルを除く）。

## データの共有

本アプリは、ユーザーが設定した AI サービス（Anthropic Claude API）以外の第三者にデータを送信しません。

Anthropic のデータ取り扱いについては、[Anthropic のプライバシーポリシー](https://www.anthropic.com/privacy)をご確認ください。

## 第三者サービス

本アプリは以下の第三者サービスを利用する場合があります。

- **Anthropic Claude API**: ユーザーが入力した API キーを使って、ユーザー自身のアカウントで利用されます
- **Google Health Connect**: ユーザーが許可した場合のみ、睡眠データの読み取りに使用されます

## データの削除

アプリをアンインストールすることで、端末内の全データ（会話履歴、設定、暗号化された API キー）が削除されます。アプリ内からも個別の会話履歴を削除できます。

Anthropic に送信されたデータの削除については、Anthropic のポリシーに従います。

## 子どものプライバシー

本アプリは 13 歳未満の子どもを対象としていません。

## 変更について

本ポリシーは予告なく変更されることがあります。重要な変更がある場合はアプリ内で通知します。
