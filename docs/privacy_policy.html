プライバシーポリシー

最終更新日: 2026年7月12日

本プライバシーポリシーは、Android アプリ「となり」（以下「本アプリ」）におけるデータの取り扱いについて説明します。

本アプリの概要

本アプリは、ユーザーが自身で用意した AI サービスの API キーを使用して、AI との対話を行うコンパニオンアプリです。対応する AI サービスは Anthropic Claude API および OpenAI 互換 API（OpenAI、Groq 等）です。

収集・使用するデータ

本アプリは以下のデータを端末上で取得し、ユーザーが設定した AI サービスへの送信に使用します。いずれもユーザーが明示的に機能を有効にした場合にのみ取得されます。

データの種類用途送信先
カメラ画像（前面・背面）HeartBeat 機能で AI に周囲の状況を伝えるユーザーが設定した API サービス
マイク音声HeartBeat 機能で AI に周囲の音を伝えるユーザーが設定した API サービス
位置情報AI に現在地の情報を伝える。場所トリガー（ジオフェンス）の判定ユーザーが設定した API サービス
加速度センサー動き・姿勢の検知、睡眠判定ユーザーが設定した API サービス
再生中のメディア情報（曲名・アーティスト名等）AI に再生中の曲を伝える。通知アクセス許可はメディア情報の取得のみに使用し、通知の内容は読み取りませんユーザーが設定した API サービス
スクリーンショット（画面の内容）AI に画面の内容を伝えるユーザーが設定した API サービス
睡眠データ（Health Connect）睡眠の記録・AI への共有ユーザーが設定した API サービス

バックグラウンドでのデータ収集

HeartBeat 機能を有効にしている間、本アプリはアプリを閉じているときや使用していないときも、ユーザーが設定した間隔で上記のデータ（位置情報を含む）を収集し、設定された AI サービスに送信します。収集中は常設通知が表示されます。

場所トリガー（ジオフェンス）を有効にした場合も、アプリを使用していない間に位置情報が使用されます。

これらの機能を初めて有効にする際には、アプリ内で収集内容の開示と同意の確認を行います。機能はいつでも設定からオフにできます。

健康データ（睡眠）の取り扱い

ユーザーが許可した場合のみ、Google Health Connect から睡眠データ（就寝・起床時刻等）を読み取ります。

  • 用途: 睡眠ログの表示と、AI が生活リズムを理解して話しかけるためにのみ使用します
  • 保存: 睡眠ログは端末内にのみ保存されます
  • 共有: ユーザーが設定した AI サービス以外には送信されません。広告や分析には一切使用しません
  • 削除: アプリ内から削除でき、アンインストールで全て消去されます。Health Connect の許可はいつでも取り消せます

データの保持（Retention）

本アプリのデータはすべてユーザーの端末内でのみ保持されます。開発者はいかなるユーザーデータも受信・保持しません。開発者がアクセスできるサーバーやデータベースは存在しません。

データの種類保持場所保持期間
会話履歴・日記・セッションレター端末内のローカルデータベースユーザーが削除するまで
睡眠ログ端末内のローカルデータベースユーザーが削除するまで
カメラ画像・マイク音声・スクリーンショット・位置情報・加速度・再生中メディア情報送信時のみの一時処理AI への送信後は保持しません（チャットに添付した画像のサムネイルは会話履歴の一部として端末内に残ります）
設定・API キー端末内（API キーは Android Keystore で暗号化）アンインストールまで

ユーザーが設定した AI サービスに送信されたデータの保持は、当該サービスのポリシーに従います（後述「データの共有」参照）。

データの削除（Deletion）

  • アプリ内での削除: 会話履歴・日記・睡眠ログ等は、アプリ内からいつでも個別に削除できます。削除は即時に反映されます
  • アンインストール: アプリをアンインストールすると、端末内の全データ（会話履歴、設定、暗号化された API キーを含む）が削除されます
  • 送信済みデータ: 各 AI サービスに送信されたデータの削除は、それぞれのサービスのポリシーおよび削除手続きに従います。開発者はデータを保有しないため、開発者側で削除すべきデータは存在しません

データの共有

本アプリは、ユーザーが設定した AI サービス以外の第三者にデータを送信しません。

データの送信先は、ユーザーが接続設定で選択した API プロバイダーおよび Base URL によって決まります。各サービスのデータ取り扱いについては、それぞれのプライバシーポリシーをご確認ください。

第三者サービス

本アプリは以下の第三者サービスを利用する場合があります。

  • Anthropic Claude API / OpenAI API / その他 OpenAI 互換 API: ユーザーが入力した API キーを使って、ユーザー自身のアカウントで利用されます。送信先はユーザーの設定により決まります
  • Google Health Connect: ユーザーが許可した場合のみ、睡眠データの読み取りに使用されます

AI が生成したコンテンツの報告

AI の応答に不適切な内容が含まれていた場合、チャットの吹き出しを長押しして「この応答を報告」から開発者に報告できます。

子どものプライバシー

本アプリは 13 歳未満の子どもを対象としていません。

変更について

本ポリシーは予告なく変更されることがあります。重要な変更がある場合はアプリ内で通知します。
