# 利用規約

最終更新日: 2026年6月20日

本利用規約（以下「本規約」）は、Android アプリ「となり」（以下「本アプリ」）の利用条件を定めるものです。本アプリをインストールまたは使用することにより、本規約に同意したものとみなされます。

## 1. 本アプリについて

本アプリは、ユーザーが自身で用意した AI サービスの API キーを使用して、AI との対話を行うコンパニオンアプリです。対応する AI サービスは Anthropic Claude API および OpenAI 互換 API（OpenAI、Groq 等）です。AI の応答は各サービスの API を通じて生成されます。

本アプリの開発者は AI サービス自体の提供者ではなく、AI の応答内容について責任を負いません。

## 2. API キーについて

- 本アプリを使用するには、ユーザー自身が AI サービスのプロバイダーから取得した API キーが必要です
- API キーの取得・管理・利用料金の支払いはユーザーの責任となります
- API キーは端末内に暗号化して保存され、ユーザーが設定した API サービスへの通信にのみ使用されます。Claude 用と OpenAI 用の API キーは別々に保存されます
- API の利用には各サービスの利用規約が適用されます（例: [Anthropic 利用規約](https://www.anthropic.com/legal/consumer-terms)、[OpenAI 利用規約](https://openai.com/policies/terms-of-use)）

## 3. データの取り扱い

本アプリにおけるデータの取り扱いについては、別途定める[プライバシーポリシー](privacy_policy.md)をご確認ください。

要点は以下の通りです:
- 会話履歴・日記・設定などのデータは端末内にのみ保存されます
- 開発者のサーバーにデータが送信されることはありません
- センサーデータ（カメラ・位置情報など）は、ユーザーが各機能を有効にした場合にのみ取得・送信されます

## 4. 禁止事項

本アプリを以下の目的で使用することを禁止します:
- 法令に違反する行為
- 各 AI サービスの利用ポリシーに違反するコンテンツの生成
- 第三者の権利を侵害する行為
- 本アプリの改変・リバースエンジニアリング

## 5. 免責事項

- **AI の応答について**: AI の応答は自動生成されたものであり、正確性・適切性を保証するものではありません。重要な判断に AI の応答のみを根拠とすることは避けてください
- **サービスの継続性について**: HeartBeat などのバックグラウンド機能は、端末の省電力設定や OS の制約により中断される場合があります。動作の継続を保証するものではありません
- **データの保全について**: 端末の故障・紛失・アプリの削除などにより、保存されたデータが失われる場合があります。大切なデータは定期的にエクスポート機能でバックアップしてください
- **API の利用料金について**: 本アプリの使用により発生する各 AI サービスの利用料金はユーザーの負担となります。画像送信やセンサーデータの送信を有効にした場合、テキストのみの場合と比べて料金が高くなることがあります
- **損害について**: 本アプリの使用または使用不能により生じた損害について、開発者は一切の責任を負いません

## 6. 対象年齢

本アプリは18歳以上の方を対象としています。

本規約は、必要に応じて予告なく変更される場合があります。変更後の規約は本ページに掲載された時点で効力を生じます。
